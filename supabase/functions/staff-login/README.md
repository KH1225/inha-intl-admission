# 직번 로그인 서버 함수 (staff-login)

로그인 화면에서 **직번 + 비밀번호**를 받아 서버 안에서 로그인합니다.
교직원의 로그인 이메일은 브라우저로 나가지 않으며, 같은 직번으로 15분 안에 5번 틀리면 15분 동안 잠깁니다.

## 순서 (꼭 이 순서대로)

1. **모든 사용 중 계정에 직번 넣기**
   현황판 → 계정 관리에서 직번이 비어 있는 계정이 없는지 확인 (본인 총괄관리자 계정 포함)

2. **서버 함수 배포**
   Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**
   - 함수 이름: `staff-login` (정확히 이 이름)
   - 이 폴더의 `index.ts` 내용을 통째로 붙여 넣고 **Deploy**
   - 배포 후 함수 설정(Details/Settings)에서 **Verify JWT** (JWT 확인) 를 **끄고** 저장
     (로그인 전에 부르는 함수라 끄지 않으면 401 오류로 로그인이 안 됩니다)

3. **현황판에서 직번으로 로그인되는지 확인**

4. **SQL 실행**
   Supabase → SQL Editor 에서 `sql/2026-11-14_직번로그인_서버처리.sql` 실행 → 두 줄 모두 `안전` 이면 완료
   (이 단계부터 로그인하지 않은 사람은 직번으로 이메일을 알아낼 수 없습니다)

Secrets 는 따로 넣을 필요가 없습니다.
